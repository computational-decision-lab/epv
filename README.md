## Repository Role

This repository is the source for the static GitHub Pages site. It contains the
reviewer interface, paper PDFs, selected figures, optimized visual assets, and
release documentation.

Full experimental source is not included in this public artifact. Private
credentials, sealed evaluation inputs, provider logs, local 4K masters, and the
complete internal research workspace are not published here.

The high-value domain scenes are deployment questions, not empirical results of
the paper. MiniWoB is the only environment in this package with a positive
heldout statistical execution-authority certificate; the independent AgentDojo
holdout does not confirm transfer.
